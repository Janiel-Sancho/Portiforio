Portfólio pessoal

Site pessoal desenvolvido para o trabalho da disciplina de Interface Homem-Máquina.

O projeto

A página apresenta o aluno, sua formação, experiência, habilidades e formas de contato.

Tecnologias

- HTML5 semântico
- CSS3: variáveis, Flexbox, Grid, responsividade e animação simples
- Link para iniciar uma conversa por e-mail no Gmail
- Imagens SVG salvas localmente no projeto

Arquivos

- `html/index.html`: conteúdo da página
- `html/projetos.html`: página separada de projetos e portfólio
- `css/style.css`: estilos e layout
- `assets/img/perfil.jpg`: foto usada na página inicial
